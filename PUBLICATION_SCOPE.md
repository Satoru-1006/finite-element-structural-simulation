# Public publication scope

## Included

The public repository includes the complete finite-element project tree found under `C:\Users\86198\Desktop\Files\有限元分析`, including source programs, Abaqus model/input/output files, tabulated data, figures, reports, rendered pages and original archive packages.

The project is presented as a research and teaching archive. Existing report revisions are preserved instead of silently collapsing them into one “final” file, because the revisions are part of the provenance of the work.

## Excluded

Only local-runtime material was withheld:

1. `task6/tsk6.3/ExampleC_SpaceFrame_SFSM.env` — local Abaqus environment state, paths and runtime variables.
2. `task9/output/R-4.6.0-win.exe` — third-party R installer, not an analysis input or result.
3. Generated Python bytecode, editor lock files and Abaqus cache metadata — reproducible local cache, not research evidence.

No source model, result table, solver output, report, figure or analysis script was intentionally removed.

## Claim boundary

The numerical comparisons are claims about the saved computational models and saved outputs. They do not constitute experimental validation, production release, fatigue qualification, structural safety certification or hardware testing.
