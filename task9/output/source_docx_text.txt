4. 为什么有限元分析通常从弱形式或能量原理出发，而不是直接从偏微分方程强形式求解？
095: 平面弹性问题的强形式为：
096: 由于应力与位移的一阶导数有关，强形式方程中将包含位移的二阶导数，因此对近似位移函数的光滑性要求较高。
097: 而三节点三角形单元的位移插值函数通常只能保证单元之间位移连续，即满足 C0C^0C0 连续性，不能保证位移导数在相邻单元之间连续，因此不适合直接求解强形式方程。
098: 通过虚功原理或最小势能原理，可将控制方程转化为弱形式。弱形式只要求位移函数具有一阶导数，降低了对插值函数连续性的要求，使常用的三节点三角形单元能够使用。
099: 此外，弱形式还具有以下优点：便于施加边界条件，便于单元组装，适用于复杂几何与复杂载荷。
100: 因此，有限元分析通常从弱形式或能量原理出发，而不是直接从偏微分方程的强形式出发。

149: 1. 请说明单元刚度矩阵组装为总体刚度矩阵的基本原则：
150: 在有限元方法中，每一个单元都有一个局部刚度矩阵 ，它表示该单元内部节点之间的刚度关系。为了得到整个结构的刚度特性，需要将所有单元的刚度矩阵按节点连接关系累加到一个“大系统”矩阵中，这个大系统矩阵称为总体刚度矩阵 。
151: 总体刚度矩阵的组装遵循以下基本原则：
152: 兼容性条件（Compatibility）：任意连接单元在公共节点的位移必须相同，因此单元刚度矩阵中对应的自由度需要“映射”到总体刚度矩阵的对应自由度位置。 
153: 力平衡条件（Equilibrium）：在每个节点处，来自所有单元的等效力的总和必须等于节点上外力或反力的总和。

239:         n4 = n3+1;                   % 右上

241:         elements = [elements;
242:                     n1, n2, n4;
243:                     n1, n4, n3];
244:     end
245: end
246: nelem = size(elements,1);
247: %% 3. 总体刚度矩阵组装
248: ndof = 2 * nnodes;
249: K = sparse(ndof, ndof);
250: F = zeros(ndof, 1);
251: elem_B = cell(nelem,1);
252: elem_A = zeros(nelem,1);
253: for e = 1:nelem
254:     enodes = elements(e,:);
255:     xe = nodes(enodes,1);
256:     ye = nodes(enodes,2);
257:     x1 = xe(1); x2 = xe(2); x3 = xe(3);
258:     y1 = ye(1); y2 = ye(2); y3 = ye(3);
259:     % 三角形面积
260:     A = 0.5 * det([1 x1 y1;
261:                    1 x2 y2;
262:                    1 x3 y3]);

265:     end
266:     % 常应变三角形单元 B 矩阵
267:     B = 1/(2*A) * [y2-y3, 0,     y3-y1, 0,     y1-y2, 0;
268:                    0,     x3-x2, 0,     x1-x3, 0,     x2-x1;
269:                    x3-x2, y2-y3, x1-x3, y3-y1, x2-x1, y1-y2];
270:     Ke = t * A * (B' * D * B);
271:     dof = [2*enodes(1)-1, 2*enodes(1), ...
272:            2*enodes(2)-1, 2*enodes(2), ...
273:            2*enodes(3)-1, 2*enodes(3)];

284: for k = 1:length(right_nodes)-1
285:     nA = right_nodes(k);
286:     nB = right_nodes(k+1);
287:     yA = nodes(nA,2);
288:     yB = nodes(nB,2);
289:     Le = abs(yB - yA);
290:     f_edge = q * t * Le / 2;
291:     F(2*nA-1) = F(2*nA-1) + f_edge;
292:     F(2*nB-1) = F(2*nB-1) + f_edge;
293: end
294: %% 5. 左边界固定边界条件
295: left_nodes = find(abs(nodes(:,1)) < 1e-12);
296: fixed_dof = [];

298:     fixed_dof = [fixed_dof, 2*left_nodes(k)-1, 2*left_nodes(k)];
299: end

302: %% 6. 求解总体方程 Kd = F

304: d(free_dof) = K(free_dof, free_dof) \ F(free_dof);

312:     dof = [2*enodes(1)-1, 2*enodes(1), ...
313:            2*enodes(2)-1, 2*enodes(2), ...
314:            2*enodes(3)-1, 2*enodes(3)];
315:     de = d(dof);
316:     strain = elem_B{e} * de;
317:     stress = D * strain;
318:     elem_strain(e,:) = strain';
319:     elem_stress(e,:) = stress';
320: end

528: 3. 对常应变三角形单元，单元内应变和应力是否随坐标变化？为什么？

531: 常应变三角形单元采用线性位移插值形函数，在该单元内任一点的位移是节点位移的线性组合。 
532: 对位移场求导得到应变时，导数是形函数的一阶导数，而对于线性形函数这些导数是常数。

536: 单元内应变、应力分布被强制为常量，无法反映真实空间中应力应变的变化。

577: 杆单元、梁单元与平面三角形单元在有限元建模思想上有哪些共同点？
578: 杆单元、梁单元与平面三角形单元在有限元建模思想上具有相同的基本出发点，都是把原本连续的结构或区域离散成有限数量的单元，并通过节点来连接各个单元。无论是一维的杆、梁，还是二维的三角形单元，本质上都是用简单单元近似复杂结构，再通过节点自由度描述结构的变形状态。它们都需要根据单元的位移模式或形函数，建立单元内部位移、应变和力之间的关系。
579: 同时，这几类单元都需要先建立各自的单元刚度矩阵，再按照节点编号和自由度编号组装成总体刚度矩阵，最终形成总体有限元方程并求解节点位移。虽然杆单元主要描述轴向拉压，梁单元还考虑弯曲变形，平面三角形单元用于描述二维平面应力或应变问题，但它们都遵循“单元离散—形函数插值—单元刚度推导—总体组装—边界条件处理—求解结果”的基本有限元分析流程。
580: 为什么二维单元的刚度矩阵推导比一维单元更复杂？
581: 二维单元的刚度矩阵推导比一维单元更复杂，主要是因为二维问题的几何区域和自由度更多。一维杆单元或梁单元通常只沿一个方向建立坐标关系，单元长度、节点自由度和位移函数都比较简单；而二维单元需要同时考虑 和 两个方向的坐标变化，每个节点通常具有 、 两个位移自由度，因此位移场、应变场和刚度矩阵的维度都更高，计算过程也更复杂。
582: 另外，二维单元还需要建立形函数矩阵 、应变矩阵 和材料本构矩阵 之间的关系。对于平面三角形单元，需要根据节点坐标推导面积、形函数及其对 、 的偏导数，再由 、、 组成应变向量，并通过平面应力或平面应变本构关系求应力。因此二维单元不仅涉及更多自由度，还涉及坐标变换、面积积分和多分量应力应变关系，所以刚度矩阵推导比一维单元更复杂。
583: 三角形常应变单元的优点和局限性是什么？
584: 三角形常应变单元的优点是形式简单、计算方便。它只有三个节点，每个节点通常包含 、 两个位移自由度，位移插值函数和应变矩阵 的推导都比较直观，因此适合用于有限元方法的基础学习、手算推导和 MATLAB 程序实现。
585: 它的另一个优点是对复杂几何区域的适应能力较强。由于三角形单元可以灵活拼接，所以在处理不规则边界、孔洞、斜边或复杂结构外形时，比规则矩形单元更容易进行网格划分。因此，在工程建模中，三角形单元常用于复杂区域的离散。
586: 但三角形常应变单元也有明显局限性。由于该单元内的应变矩阵 为常量，所以单元内应变和应力也是常量，不能反映单元内部应力随坐标的连续变化。当网格较粗或应力梯度较大时，计算结果容易出现精度不足、应力分布块状明显、位移偏小和刚度偏大的问题，因此通常需要加密网格或采用更高阶单元来提高精度
587: 如果将本题从常应变三角形单元改为四节点矩形单元，计算结果可能有哪些变化？
588: 如果将本题中的三角形常应变单元改为四节点矩形单元，计算结果通常会更加平滑，位移和应力分布也会更接近连续场。因为常应变三角形单元的单元内应变、应力为常量，所以应力云图容易呈现分片块状；而四节点矩形单元一般采用双线性位移插值，可以在单元内部描述更丰富的位移变化，因此对于矩形板这种规则几何问题，位移场和应力场的表现通常会更加连续、自然。常应变三角形单元本身近似的是单元内常应力、常应变场；有限元结果精度也通常需要通过网格加密来改善。
589: 同时，四节点矩形单元在规则矩形区域中划分更方便，单元形状与矩形板几何更一致，可能减少由于三角形剖分方向带来的局部误差，使右端位移、板中部 等结果更稳定。对于本题的均匀拉伸问题，理论上 应接近 ， 和 应接近 0；使用四节点矩形单元后，这些结果在板中部区域可能更接近理论值，应力云图也会比 CST 单元更平滑。
590: 不过，四节点矩形单元也不是一定在所有情况下都更好。它对网格形状的规则性要求更高，如果几何边界复杂或单元畸变严重，计算精度也会下降；而三角形单元虽然精度较低，但更容易适应复杂边界。因此，对于本题这种规则矩形板，改用四节点矩形单元通常会提高结果平滑性和位移、应力精度；但对于复杂几何问题，三角形单元仍然具有网格划分灵活的优点。
591: 对于边界附近的应力扰动区，为什么有限元法比简单解析方法更有优势？
592: 对于边界附近的应力扰动区，有限元法比简单解析方法更有优势，是因为解析方法通常需要较理想的边界条件和规则的应力状态。例如均匀拉伸解析解一般假设板内应力分布比较简单， 近似为常量， 和 接近零。但在本题中，左边界完全固定会限制板的横向泊松收缩，使固定端附近产生局部二维应力扰动，这种局部扰动很难用简单解析公式准确表达。
593: 有限元法则可以直接在模型中施加真实的边界约束和载荷条件，把矩形板离散成很多单元后，通过整体刚度矩阵求解各节点位移，再进一步计算每个单元的应变和应力。因此，即使边界附近存在 、 等复杂应力分量，有限元法也能通过局部单元结果反映出来，而不是只能给出一个理想化的整体解析值。
594: 所以，对于边界附近这种应力变化快、受约束影响明显的区域，有限元法能够更直观地显示应力集中、局部扰动和应力重新分布情况。相比简单解析方法，它更适合处理实际工程中复杂边界、局部约束和非均匀应力场问题。
