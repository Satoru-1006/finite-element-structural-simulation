# 基于三角形常应变单元的矩形方板拉伸有限元分析

## 摘要

矩形方板拉伸是验证平面弹性有限元方法的典型算例。本文以左边界固定、右边界受 x 方向均布拉应力、上下边界自由的矩形薄板为对象，在平面应力假设下建立三角形常应变单元有限元模型。基于虚功原理和最小势能原理，推导位移插值、形函数矩阵、应变-位移矩阵、平面应力本构矩阵、单元刚度矩阵和右边界等效节点载荷向量，并利用 MATLAB 程序完成总体刚度矩阵组装、位移边界条件处理、节点位移求解及单元应力后处理。结果表明，x 方向位移沿板长方向逐渐增大，y 方向位移体现泊松收缩及固定端约束影响；板中部 σx 与 100 MPa 理论拉应力接近，而 σy 和 τxy 在固定端附近出现局部扰动。该差异主要来源于常应变三角形单元的低阶近似、网格粗细以及左边界完全固定对横向变形的限制。网格加密、局部细化和采用高阶单元可进一步改善位移与应力精度。

关键词：有限元法；三角形常应变单元；平面应力；矩形方板；MATLAB；应力分析

## 1 引言

薄板在拉伸载荷下的变形和应力分布是机械结构设计与有限元教学中的基础问题。对于几何形状规则、载荷和约束条件理想化的构件，弹性力学可以给出均匀拉伸状态下的解析解。然而，当边界约束限制泊松收缩、载荷需要通过节点力等效引入，或需要分析固定端附近的局部应力扰动时，简单解析解往往不能完整反映结构响应。

有限元方法通过将连续体区域离散为有限数量的单元，将平面弹性偏微分方程边值问题转化为有限维代数方程组。与直接求解强形式方程相比，基于虚功原理或能量原理建立的弱形式对位移插值函数的光滑性要求较低，因而适用于三角形常应变单元等低阶单元。

本文以矩形方板拉伸问题为研究对象，采用三节点三角形常应变单元建立平面应力有限元模型。研究内容包括平面弹性弱形式建立、CST 单元公式推导、右边界等效节点载荷构造、总体刚度矩阵组装、MATLAB 数值实现以及与理论均匀拉伸解的对比分析。原始课程报告中的真实 MATLAB 程序、网格图、位移场、应力场和结果对比表被保留并整合为连续论文叙述。

## 2 理论基础

### 2.1 平面弹性问题基本假设

矩形方板长度为 L，高度为 H，厚度为 t。材料被视为线弹性、各向同性材料，弹性模量为 E，泊松比为 ν。由于板厚小于面内尺寸，且载荷主要作用于板面内，本文采用平面应力假设，即厚度方向应力可忽略。模型中忽略体力项，外载荷由右边界沿 x 方向的均布拉应力 q 等效为节点力引入。

### 2.2 虚功原理与最小势能原理

平面弹性问题的有限元控制方程可由虚功原理建立。对于任意满足位移边界条件的虚位移，结构内部应力虚功应等于外力虚功：

式（1）  ∫Ω δεᵀσ dΩ = ∫Ω δuᵀb dΩ + ∫Γt δuᵀt̄ dΓ

在线弹性稳定结构中，最小势能原理与虚功原理等价。真实位移场使总势能在所有满足位移边界条件的许可位移场中取极小值：

式（2）  Π(u) = 1/2 ∫Ω εᵀDε dΩ − ∫Ω uᵀb dΩ − ∫Γt uᵀt̄ dΓ

弱形式只要求位移函数具有一阶导数，降低了对插值函数连续性的要求。三节点三角形单元通常只能保证相邻单元之间位移连续，不能保证位移导数连续，因此从虚功或能量形式出发比直接求解强形式更合适。

### 2.3 平面应力本构关系

在小变形和线弹性假设下，应力与应变满足平面应力本构关系：

式（3）  σ = Dε，D = E/(1−ν²) [[1,ν,0],[ν,1,0],[0,0,(1−ν)/2]]

该本构矩阵将三分量应变向量 ε=[εx, εy, γxy]ᵀ 与应力向量 σ=[σx, σy, τxy]ᵀ 相联系，是后续单元刚度矩阵和应力计算的基础。

## 3 三角形常应变单元理论

### 3.1 节点自由度与位移插值

三节点三角形单元的节点记为 i、j、m，每个节点具有 x 和 y 两个方向的位移自由度。单元节点位移向量为 de=[ui, vi, uj, vj, um, vm]ᵀ。单元内部位移采用一次多项式近似：

式（4）  u(x,y)=a1+a2x+a3y，v(x,y)=a4+a5x+a6y

一次位移模式包含六个待定系数，与三节点三角形单元的六个节点位移自由度相对应，因此可由节点位移唯一确定单元内位移场。

### 3.2 形函数矩阵

单元内任意点位移可由三个节点位移通过形函数插值得到：

式（5）  {u,v}ᵀ = Nde，N = [[Ni,0,Nj,0,Nm,0],[0,Ni,0,Nj,0,Nm]]

形函数反映各节点位移对单元内部任意一点位移的贡献。三角形线性形函数满足节点插值性质和单位分解性质，即自身节点取 1、其他节点取 0，且 Ni+Nj+Nm=1。

### 3.3 应变-位移矩阵

平面小变形应变由位移导数给出：

式（6）  ε = [εx, εy, γxy]ᵀ = [∂u/∂x, ∂v/∂y, ∂u/∂y+∂v/∂x]ᵀ = Bde

三节点三角形单元的应变-位移矩阵可写为：

式（7）  B = 1/(2A) [[bi,0,bj,0,bm,0],[0,ci,0,cj,0,cm],[ci,bi,cj,bj,cm,bm]]

其中 A 为三角形面积，b 和 c 系数由节点坐标差确定。由于形函数为一次函数，形函数导数在单元内部为常数，因此 B 矩阵为常量，单元内应变和应力也为常值。

### 3.4 单元刚度矩阵

将位移插值和本构关系代入虚功方程，可得到单元刚度矩阵：

式（8）  Ke = ∫Ωe BᵀDB t dΩ

对于三角形常应变单元，B 和 D 在单元内均为常量，因此单元刚度矩阵可简化为：

式（9）  Ke = t A BᵀDB

单元刚度矩阵反映单元节点力与节点位移之间的线性关系，也体现了单元抵抗变形的能力。

### 3.5 等效节点载荷向量

分布载荷应依据虚功等效原则转换为节点载荷，而不应简单人为平均分配。对于右边界长度为 Le 的线性边界单元，当均布拉应力 q 沿 x 方向作用时，两端节点在 x 自由度上的等效节点力为：

式（10）  fe = ∫Γe Nᵀt̄t dΓ，fe,x = [q t Le/2, q t Le/2]ᵀ

该处理保证连续分布载荷与离散节点力在虚功意义上等效。

## 4 矩形方板有限元模型

### 4.1 几何模型与材料参数

计算模型为矩形薄板，主要参数为 L=1.0 m、H=0.4 m、t=0.01 m、E=210 GPa、ν=0.30、q=100 MPa。单元类型为三节点三角形常应变单元，对应平面应力分析中的 CPS3/CST 模型。

### 4.2 边界条件与载荷设置

左边界施加 u=0、v=0 的完全固定约束，右边界施加沿 x 方向的均布拉力，上下边界保持自由。右边界总等效力为 q t H，数值模型中等效总力与理论总力保持一致。图 1 展示矩形方板三角形网格划分，图 2 展示边界条件与载荷设置。

### 4.3 网格划分与自由度编号

规则矩形区域被划分为三角形单元。每个节点具有两个自由度，若节点编号为 n，则 x 和 y 方向自由度编号分别为 2n−1 和 2n。原始报告比较了 2、4、8 个三角形单元时的结果，用于说明网格粗细对 CST 单元精度的影响。Abaqus 细网格结果包含 189 个节点、320 个 CPS3 单元和 9 个右边界加载节点。

### 4.4 总体刚度矩阵组装与边界条件处理

总体刚度矩阵由各单元刚度矩阵按节点连接关系和自由度编号累加得到。引入边界条件后，将自由自由度和固定自由度分离；由于固定自由度位移为零，自由自由度位移可由对应刚度子矩阵和载荷子向量求得：

式（11）  Kd = F，df = Kff⁻¹Ff

## 5 MATLAB 数值实现

### 5.1 程序流程

MATLAB 程序首先输入几何、材料和载荷参数，并建立平面应力本构矩阵 D。随后生成规则三角形网格，逐单元计算面积、B 矩阵和 Ke，并按自由度编号组装总体刚度矩阵。载荷处理阶段将右边界均布拉力转换为等效节点力；边界条件处理阶段固定左边界节点的两个位移自由度。完成线性方程求解后，程序进一步计算单元应变、单元应力，并绘制网格图、变形图、位移云图、应力云图和沿中线 σx 变化曲线。程序流程见图 3。

### 5.2 节点位移求解

在获得总体方程后，程序将左边界所有节点的两个位移自由度列入 fixed_dof，其余自由度作为 free_dof。节点位移通过求解 K(free_dof, free_dof)d=F(free_dof) 得到。固定自由度位移保持为零，从而形成完整节点位移向量。

### 5.3 单元应变与应力计算

节点位移求得后，单元节点位移向量 de 被代入应变-位移关系计算单元应变：

式（12）  εe = Bde

应力由平面应力本构矩阵计算：

式（13）  σe = Dεe = DBde

由于 CST 单元的 B 矩阵为常量，单元内应变和应力不会随坐标变化。

### 5.4 后处理与结果输出

后处理阶段将单元应力平均到节点，用于绘制平滑云图，同时保留单元常值应力图以展示 CST 单元的原始应力特征。输出结果包括节点位移、单元应力、网格图、变形图、位移云图、应力云图、中线应力曲线以及理论解对比数据。

## 6 结果与讨论

### 6.1 网格划分与变形结果

变形结果见图 4。受右端拉力作用后，矩形板整体沿 x 方向伸长；由于左边界完全固定，固定端节点位移被约束为零，变形从固定端向加载端逐渐累积。该变形趋势与单向拉伸问题的基本力学响应一致。

### 6.2 位移场分析

x 方向位移场见图 5。位移从左端到右端逐渐增大，是因为轴向位移可近似理解为从固定端到当前位置轴向应变的积分。左边界被固定为零位移，右端受拉后累计伸长最大，因此右边界 x 方向位移最大。

y 方向位移场见图 6。板在 x 方向受拉时，材料倾向于在 y 方向收缩，这是泊松效应的直接体现。然而左边界完全固定同时限制横向位移，使固定端附近的泊松收缩不能自由发展，从而导致 y 方向位移场呈现受约束后的非均匀分布。

### 6.3 应力场分析

沿中线 σx 变化曲线见图 7。理论均匀拉伸解给出 σx=q=100 MPa，σy=0，τxy=0。有限元结果中，板中部 σx 与理论拉应力整体接近，说明主要承载应力被合理捕捉。Abaqus 汇总结果显示，板中部平均 S11 为 100.179 MPa，相对误差约 0.179%。

σx、σy 和 τxy 的平滑应力云图见图 8 至图 10。σx 是主要承载应力，远离固定端后趋于均匀拉伸状态。σy 理论上应为零，但固定端附近出现非零值，原因是完全固定边界限制了横向泊松收缩，使局部区域进入二维应力状态。τxy 理论上也为零，但三角形剖分方向、局部约束扰动和离散化误差会引入小幅剪应力。

σx 单元常值应力图见图 11。由于 CST 单元采用线性位移插值，B 矩阵在单元内为常量，因此单元内应力为常值。平滑云图有利于观察整体趋势，而单元常值图更直接地反映了 CST 单元的低阶近似特征。

### 6.4 理论解与有限元解对比

原始报告在 y=0 中线上选取 x=0.25 m、0.50 m 和 0.75 m 三个位置进行理论解与有限元解对比。这三个位置分别对应板长方向的 1/4L、1/2L 和 3/4L，能够代表靠近固定端影响区、板中部区域和靠近加载端区域，同时避开 x=0 与 x=L 的边界节点，使比较结果更能反映主体区域的数值精度。

对比结果显示，有限元位移整体略小于理论均匀拉伸位移，主要原因是左边界完全固定提高了结构的等效刚度，并限制了横向泊松收缩。σx 与理论值 100 MPa 接近，网格加密后结果更稳定。σy 和 τxy 在理论均匀拉伸解中为零，但有限元中出现非零值，反映了固定端边界扰动和三角形网格离散误差。

### 6.5 误差来源分析

本问题的误差主要来自三个方面。首先，常应变三角形单元采用线性位移插值，单元内应变和应力为常值，粗网格下难以描述真实连续应力场，尤其在固定端和加载端等应力梯度较大的区域误差更明显。其次，左边界完全固定是理想化约束，它限制了横向泊松收缩，使结构整体刚度偏大，导致位移偏小，并在固定端附近诱发 σy 和 τxy 扰动。最后，均布拉力通过边界线积分等效为节点力，虽然满足虚功等效原则，但在粗网格边界上仍存在离散化近似。

提高计算精度可从网格、单元和边界条件三个方面入手。网格加密能够减小离散化误差，局部细化可重点改善固定端和加载端附近的应力梯度区域；采用二次三角形单元或四节点矩形单元可以更好地描述单元内部位移和应力变化；改进边界条件模拟方式则有助于减小完全固定约束带来的局部刚化影响。

## 7 结论

本文基于三角形常应变单元建立了矩形方板拉伸问题的平面应力有限元模型，并通过 MATLAB 程序完成了从单元刚度矩阵计算、总体组装、边界条件处理到位移和应力后处理的完整流程。计算结果与理论均匀拉伸解总体一致：x 方向位移沿加载方向逐渐增大，σx 在板中部接近 100 MPa，y 方向位移体现泊松效应。

有限元结果中 σy 和 τxy 的局部非零值主要由左端完全固定、网格离散和 CST 单元常应变近似共同造成。对于该类问题，网格加密、边界区域局部细化以及使用高阶单元能够提高位移和应力精度。与此同时，理论解析解与有限元模型的边界条件并不完全相同，因此在结果评价中应明确解析解适用范围和有限元边界扰动之间的差异。
