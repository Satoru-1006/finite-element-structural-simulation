算例 B：平面拉弯组合验证

A = 0.02 × 0.04 = 8.0e-4 m^2
I = 0.02 × 0.04^3 / 12 = 1.0666666667e-7 m^4
c = 0.02 m

理论值：
u = NL / EA = 7.142857e-5 m
v = -PL^3 / 3EI = -1.542857e-2 m
θ = -PL^2 / 2EI = -1.928571e-2 rad
σN = N / A = 12.5 MPa
σb = Mc / I = 135.0 MPa
σmax = σN + σb = 147.5 MPa
σmin = σN - σb = -122.5 MPa

Abaqus 后处理建议：
1. 位移与转角：直接读取自由端 U1、U2、UR3。
2. 固定端最大正应力：不要直接把粗网格梁单元云图上的 S, Mises 最大值当成理论对比值；
   对于本题，应优先用固定端反力和反力矩回算：
   σmax = |RF1| / A + |RM3| c / I。
3. 本模型各网格下固定端反力均为 RF1 = -10000 N，RM3 = 720 N·m，
   因而由反力回算得到的固定端最大正应力均为 147.5 MPa。
4. 梁单元积分点应力会随网格加密逐步逼近固定端理论值，不能与“固定端最大正应力”混为一谈。
